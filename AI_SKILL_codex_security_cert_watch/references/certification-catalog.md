# Cybersecurity Certification Catalog (Major Tracks)

Last reviewed: 2026-02-20

Use this as a living map. Verify each exam code/version before recommending "latest" paths.

## Vendor-Neutral Foundations

### CompTIA

- Security+: https://www.comptia.org/certifications/security
- CySA+: https://www.comptia.org/certifications/cybersecurity-analyst
- PenTest+: https://www.comptia.org/certifications/pentest
- SecurityX (advanced, formerly CASP+): https://www.comptia.org/certifications/securityx
- SecAI+: https://www.comptia.org/certifications/secai

### (ISC)2

- Certification portfolio: https://www.isc2.org/certifications
- CC, SSCP, CISSP, CCSP, CGRC, CSSLP, ISSAP, ISSEP, ISSMP (see portfolio page)

### ISACA

- Credential portfolio: https://www.isaca.org/credentialing
- CISA, CISM, CRISC, CGEIT, CDPSE, CCOA, AAIA, AAISM

### GIAC/SANS

- Certification list: https://www.giac.org/certifications/
- Renewal policy: https://www.giac.org/renewal/

## Offensive Security / Red Team

- OffSec certification catalog: https://www.offsec.com/courses-and-certifications/
- OSCP, OSEP, OSWE, OSED, OSDA, OSTH, OSIR
- OffSec exam policy/help: https://help.offsec.com/

## Cloud Security

### AWS

- Security Specialty (official page): https://aws.amazon.com/certification/certified-security-specialty/
- Exam guide and version details: https://docs.aws.amazon.com/aws-certification/latest/examguides/security-specialty.html

### Microsoft

- Azure Security Engineer Associate (AZ-500): https://learn.microsoft.com/credentials/certifications/azure-security-engineer/
- Cybersecurity Architect Expert (SC-100): https://learn.microsoft.com/credentials/certifications/cybersecurity-architect-expert/

### Google Cloud

- Professional Cloud Security Engineer: https://cloud.google.com/learn/certification/cloud-security-engineer
