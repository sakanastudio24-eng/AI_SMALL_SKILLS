# Security Cert Watch Checklist

## Pre-ship
- [ ] Latest version or retirement facts are verified
- [ ] Official sources are cited
- [ ] Role target is clear
- [ ] AI security concerns are separated from cert advice
- [ ] Inferred guidance is labeled clearly

## Edge Cases
- [ ] Provider page changed recently
- [ ] Pricing or renewal policy is outdated
- [ ] User asks for shortcut or exam cheating advice
- [ ] Accreditation claim is unverified
- [ ] Security boundary recommendation could be policy-sensitive
