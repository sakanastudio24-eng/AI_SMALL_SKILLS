# AI_SKILL_codex_security_cert_watch

## Purpose
Handle cybersecurity certification guidance and AI security boundary review with current, source-backed recommendations.

## Use When
- reviewing security certifications
- comparing cert roadmaps
- checking exam or renewal changes
- evaluating AI app-bot security guardrails
- identifying do-not-cross security boundaries

## Do Not Use When
- implementing non-security product features
- answering stale certification questions without verification
- making unrelated web UI decisions

## Inputs Needed
- certification goal or role target
- provider or cert family
- current vs latest question
- AI security boundary concern
- region or compliance context if relevant

## Steps
1. Identify whether the request is about certs, renewals, updates, or AI security concerns.
2. Verify unstable facts from official provider sources.
3. Map findings to the user’s target role or path.
4. Separate confirmed facts from inferred recommendations.
5. Return current guidance plus security guardrails.

## Output
- certification guidance
- security concern summary
- recommended path or next certs
- source-backed verification notes

## Constraints
- use official vendor sources for date-sensitive facts
- separate stable guidance from changing details
- do not invent pricing, retirement dates, or accreditation claims
- security boundary advice requires manual review before shipping policy
