# Web Checklists

## Page Structure

- State the primary user goal in one sentence.
- Put the main value explanation above secondary details.
- Keep one dominant CTA visible.
- Remove duplicate or competing actions.
- Make proof, feedback, or trust signals visible at the right moment.

## Responsive Behavior

- Confirm mobile navigation is still understandable.
- Confirm CTA placement survives narrow screens.
- Check overflow, wrapping, and scrolling behavior.
- Check that cards, tables, or forms remain usable on mobile.
- Avoid moving core actions to unpredictable locations across breakpoints.

## UX Review

- Loading state exists.
- Empty state exists.
- Validation and error states explain what to do next.
- Form labels outperform placeholders.
- Visual hierarchy makes the page scannable in under a few seconds.
