# GitHub Commits Checklist

## Pre-ship
- [ ] Each commit has one clear intent
- [ ] Lockfiles are grouped with dependency changes
- [ ] Unrelated files stay unstaged
- [ ] Commit messages explain purpose clearly
- [ ] Branch history reads cleanly for review

## Edge Cases
- [ ] Mixed refactor and behavior change
- [ ] Generated files in diff
- [ ] Broad formatting noise
- [ ] Accidental user changes staged
- [ ] Dependency bump without matching lockfile
