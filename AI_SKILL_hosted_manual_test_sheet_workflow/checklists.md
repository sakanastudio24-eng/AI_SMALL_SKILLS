# Hosted Manual Test Sheet Checklist

## Sheet Structure
- [ ] Each case has a clear name
- [ ] Steps are reproducible
- [ ] Expected result is explicit
- [ ] Owner or tester is recorded
- [ ] Environment is recorded

## Coverage
- [ ] Critical happy paths are included
- [ ] Failure paths are included
- [ ] Auth and permission states are covered
- [ ] Empty or first-run states are covered
- [ ] Release-specific risks are represented

## Outcome Tracking
- [ ] Pass / fail / blocked states are standardized
- [ ] Actual result is captured when a case fails
- [ ] Bug links are attached to failing cases
- [ ] Block reasons are concrete
- [ ] Retest ownership is clear
