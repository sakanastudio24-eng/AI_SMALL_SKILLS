# Web Design System Workflows Checklist

## Pre-ship
- [ ] Foundations are defined before component detail
- [ ] Token model is explicit
- [ ] Component states and variants are documented
- [ ] Accessibility expectations are included
- [ ] Adoption or governance notes exist

## Edge Cases
- [ ] Brand styles are hardcoded instead of tokenized
- [ ] Component variants solve only one screen
- [ ] Docs lag behind implementation
- [ ] Dark mode or multi-brand support is underspecified
- [ ] Audit findings are not prioritized by impact
