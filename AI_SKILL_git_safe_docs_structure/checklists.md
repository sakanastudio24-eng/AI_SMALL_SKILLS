# Git Safe Docs Structure Checklist

## Pre-ship
- [ ] Preflight checks were run
- [ ] Current branch is appropriate for docs work
- [ ] Renames use tracked moves where possible
- [ ] Secrets and local env files are excluded
- [ ] Before/after structure is clear in PR notes

## Edge Cases
- [ ] Broken links after move
- [ ] Duplicate docs remain in two places
- [ ] Mass rename mixed with content rewrite
- [ ] Monorepo ownership is unclear
- [ ] Canonical doc path is still ambiguous
